##Una breve explicación de lo que has observado al trabajar con:

- Ramas= Puestos de trabajo con un nombre descriptivo
- Commits= Cambios guardados listos para hacer push
- Merge= Fusionar cambios entre ramas
- Push= Manda todos los cambios de local a remoto
- Fetch= informa del estado actual del remoto
- Pull= trae los cambios del remoto al local
- Cambios realizados directamente desde GitHub= He subido la foto
